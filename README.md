# Machine learning-assisted understanding of discontinuous precipitation behavior in Cu-Ni-Si alloy
This repository provides the original experimental datasets and example code associated with the manuscript:

**“Machine learning-assisted understanding of discontinuous precipitation behavior in Cu-Ni-Si alloy”**

Submitted to *Journal of Materials Informatics*.

## Overview

This study develops an integrated classification–regression framework to predict the occurrence and volume fraction of discontinuous precipitates (DPs) in Cu–Ni–Si alloys using alloy composition and processing parameters.

## Repository Contents

- Original experimental datasets supporting the classification and regression analyses.
- Example code illustrating the data-processing and modeling procedures.

## Data Description

The input variables are:

- **Ni**: Ni content (wt.%).
- **Si**: Si content (wt.%).
- **CR**: Cold-rolling reduction (%).
- **AT**: Aging temperature (°C).

The target variables describe DPs occurrence and volume fraction. DPs occurrence is encoded as 0 (absence) or 1 (presence). Volume fractions are expressed as percentages; for example, a value of 2.0 represents 2.0%.
